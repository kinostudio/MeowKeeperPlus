# 總覽／即時畫面共享播放與收音

## 行為契約

- 總覽、即時畫面共用同一份已登入文件；一般同分頁導覽、上一頁／下一頁只切換可見區域。
- 保留同一個 video、MSE／WebRTC session、播放模式、靜音偏好與 JPEG 最後影格，不因切頁重新協商或重接來源。直接開啟總覽預設節能，直接開啟即時畫面預設流暢；兩頁間切換沿用目前模式。
- 其他設定頁仍正常導覽並釋放播放器；新分頁、重新整理、來源切換、播放失敗及主動改模式可能建立新播放 session。不是跨分頁永久播放器。
- 隱藏的即時頁不得攔截方向鍵或持續進行 PTZ 初始讀取；離開時保留停止馬達處理。服務資訊卡與既有內容不精簡。

## 收音契約

- 預設靜音；取消靜音不等於攝影機有音軌，也不等於使用者喇叭已發聲。
- 原碼 MSE 協商包含瀏覽器可解碼的音訊；H.264 相容分支沿用同一個共用轉碼程序，以可選音軌轉為有界 AAC，不新增攝影機 producer。沒有音軌時仍可播放影片。
- UI 區分等待音軌、已取得音軌、無音軌及瀏覽器阻擋播放，不再僅因按下收音就宣稱成功。
- Xiaomi 明確保存的 `audio=0` 不自動改寫。使用者確認啟用來源收音後，才沿用既有暫停／同來源更新／驗證新影格／恢復流程；失敗回復原偏好。來源設定與前端靜音是不同操作。
- 中繼不擅自改遠端來源，需在提供端設定。偏好只保存布林值，不保存私人來源網址。

## 可執行驗收

- `tests.test_monitor_navigation`：共享版型、唯一 DOM ID、登入保護、導覽生命週期。
- `tests.test_source_audio`：明確啟用、偏好記憶、登入／CSRF／重接確認、失敗回復、無音軌不得冒充成功。
- `tests.test_preview_transcode.RealTranscodeTests`：需設定 `RUN_MEOWKEEPER_RELAY_MEDIA=1`；合成 HEVC 與非靜音音訊、雙觀看者共用轉碼、清理。
- 若另設定 `MEOWKEEPER_PLAYWRIGHT` 指向已安裝 Playwright，實際 Edge 驗證8次切頁只有1條媒體 WebSocket、同一 video／來源持續播放、音訊解碼、休眠與390px布局。
- `tests.test_preview_rtc`：真實隔離 peer、授權撤銷與有界封包佇列。

隔離合成音訊不代表真實攝影機或使用者喇叭驗收。正式包、正式 Host 程式部署與各瀏覽器相容性須獨立記錄；實機細節只留本機忽略目錄，不放公開文件。
