# 產品路線

## 共同來源與可靠交付

使用同一 GitHub 原始碼、固定 commit 交接、完整來源／測試雜湊與可重現隔離驗證；公開程式與私人實機紀錄分離。

## 穩定核心

維持單一上游影音、事件快取與 Telegram 優先順序，完善資料根目錄、歷史媒體播放、備份還原、程序停止與失敗回復。

## 使用體驗

完善新手攝影機接入、預覽模式、PTZ 位置讀回、非打擾保存提示、可互動硬體趨勢與可理解的失敗原因。

## 候選能力驗證

對家庭實拍資料驗證 DINOv2 身分候選、人工證據保護、行為參考與選用視覺 API；保持 experimental，分開評估樣本品質、準確性、負載及通知延遲。

## 正式產品

目標硬體長測、乾淨 Windows 發布環境、跨版本資料遷移、授權審核及完整外部端到端驗收後，再判定版本支援範圍。實際驗收狀態留在本機報告；公開文件不據此保證所有裝置。
