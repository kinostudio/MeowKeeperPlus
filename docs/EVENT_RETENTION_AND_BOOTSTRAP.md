# 事件保留與差量引導修正

## 事件影片

- 預設保留 30 天、容量 3,221,225,472 bytes；「30 天」是清理資格門檻。正常六小時掃描可能留下最多約六小時的過期空窗。
- 原本只在影格分析循環執行掃描，斷訊或推論停滯會延後清理；單檔占用會令整輪中止，也沒有成功零刪除的執行證據。
- 改成首次啟動監控時建立單一背景維護工作，不等待攝影機影格，正常每六小時掃描；占用或錯誤時五分鐘後重試。關閉 Host 會停止維護工作，不開攝影機連線。
- 只處理事件根目錄第一層指定影片副檔名，不處理 SQLite、設定、照片、子目錄或重新解析點。最近十分鐘建立／寫入的檔案受到保護；刪除前重查大小及修改時間。Windows 讀寫占用或檔案變動時略過，不因單檔錯誤中止其餘清理。
- `metrics.event_retention` 提供檢查時間、下次時間、政策、刪除數量、保護數量與占用數量，不包含私人檔案路徑。日誌每次留下安全摘要。
- 保護／占用檔案可令容量暫時超標。事件影片限制不是整個 Data 的總容量限制。

## 差量引導

- 差量 ZIP 僅包含改動檔案。更新器不能假設未變更的 PowerShell worker 與驗證工具一定存在於解壓目錄。
- 引導器補齊三個控制檔：PowerShell worker、worker-side Python verifier、delta verifier。只接受符合簽章目標清單的檔案；未變更檔案從已驗證的本機基準複製，變更檔案沿用經驗證的差量內容。
- 缺檔或雜湊不符時，在啟動安裝前停止，不下載完整 runtime、不停止監控。
- 正式版本仍需使用者核准安裝並實機驗收；隔離測試不代表正式 Host 已升級或已清理。

## 可執行回歸

故障台帳：`EVENT-RETENTION-INDEPENDENT-SAFE-SWEEP`、`DELTA-UNCHANGED-BOOTSTRAP-TOOLS`；詳見 `configs/release-regressions.json`。
