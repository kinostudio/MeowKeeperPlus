## 本輪完成條件

1. 共享布局採米白／橘棕／大地色、224px 側欄、分組導覽、72px 頂列，所有既有頁面仍可操作。
2. 首頁以影格／AI／Telegram 三個真實狀態、單一共享預覽、事件卡與真實資源圖表為主。
   缺值、逾時與實驗性結果明確標示；不造假圖表或增加 ingest。
3. 頁尾顯示執行版本及可攜／安裝／開發狀態，從發布 manifest 讀取，不寫死 r93。
4. Telegram 同列「回饋／通知／冷卻」；回饋點擊切換，通知可開／關或輸入整數靜音小時，
   冷卻點擊後輸入整數分鐘。數字輸入只對已授權私人對話有效、具有時效與取消方式。
5. Telegram operator 可「儲存位置／位置一／位置二」；每台相機最多兩個，輪流覆寫，
   只保存已讀回座標；回到位置需實際讀回一致才報成功。不改已有隱私位置資料。
6. 保留 `/cd`、`/mute`、`/feedback` 舊指令與每人權限、偏好、SQLite 回饋歷史及單一監控來源。
7. 測試、Ruff、compileall、秘密掃描、桌面與窄版瀏覽器檢查及可攜包驗證；
   真實 Telegram／PTZ 未驗收則標 not_checked，不以 Mock 冒充。

## 順序

先修共享布局與版本資訊，再接首頁真實資料圖表；接 Telegram 設定互動與位置服務，
執行隔離測試及視覺驗收，最後建立新包並提供升級代碼。使用者自行安裝，不自動 UAC 或重啟正式 Host。
