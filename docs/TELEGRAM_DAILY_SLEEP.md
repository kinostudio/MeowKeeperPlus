# Telegram 每日靜音

每位已授權 Telegram 用戶可自行設定，其他用戶不受影響。

- `/sleep 23-8`：每天 23:00（含）至翌日 08:00（不含）停止傳送貓咪事件通知。
- `/sleep 9-17`：每天 09:00 至 17:00 停止傳送貓咪事件通知。
- `/sleep` 或 `/sleep status`：查看自己的設定與目前是否在靜音時段。
- `/sleep off`：關閉每日靜音，不變更通知總開關、臨時靜音或冷卻。

採用 **Host 電腦當地時間**，不是手機時區；跨住處使用時請確認 Host 的 Windows 時區。只接受 0～23 的整點，起訖不得相同。結束時段後仍須符合通知總開關及冷卻規則。

偵測、影音快取及本地事件保存持續；手動指令回覆與非貓咪警示不受此時段限制。`/unmute` 只解除臨時靜音，不取消每日時段。

設定保存於既有 `telegram-cat-notifications.json` 通知偏好檔案（實際路徑由 Host 資料目錄決定），收件者僅保存雜湊識別；重啟後保留。不需要新增 Telegram poller 或重啟才能使已載入此功能的 Host 套用新時段。

本次僅修改來源程式與相關測試，未建置、安裝或重啟正式 Host。Telegram 真實指令驗收須待後續發布並部署後執行。
