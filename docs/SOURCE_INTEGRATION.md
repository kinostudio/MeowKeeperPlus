公開樹只保留程式、測試及一般說明。原實機報告、具名電腦的部署工具及私人位址已自目前公開樹移除；原資料先封存於維護者本機，未刪除使用者資料。通用中繼程式保留，診斷工具不再寫死實際設備位址。

以 main 為父提交的 squash 整合避免把舊工作分支中的實機文件祖先帶入 main；但舊公開分支／提交曾存在的內容不因此從 GitHub 歷史抹除。不可宣稱已完成歷史清除；若需移除既有公開歷史，應另行審查與授權。
