# 輔助辨識：環境物件與視角校正（歷史實驗流程）

> **目前介面界線（2026-10-17）**：寵物檔案頁只登錄寵物名稱與 AI 參考照片，供個體外觀比對；不需設定攝影機角度或場景物件。場景物件參考另在「設定 → AI 與行為參數」管理，可保存目前畫面或上傳參考照、拖曳圈選與本機預覽拼貼；場景照片預設不外送。選用 API 外送需在 AI 管理中心對場景參考另行同意，且不把場景拼貼當作身分或行為證據。

以下為此前試行的環境物件／視角工作流程記錄，不是目前寵物登錄的操作要求：

1. 填視角名稱，使用穩定的目前畫面；也可上傳4MB內參考照片，僅保存在本機。
2. 在圖片上拖曳框住物件，不需要填百分比；填名稱、用途後保存。
3. 上傳圖先視為未校正。若要用於攝影機位置判斷，將鏡頭轉回該方向，展開「把物件位置套用到目前攝影機」，按「核對目前畫面與這張參考圖」。

鏡頭移動、畫質改動、背景不一致、物件位置改動都會使舊位置失效；失效不停止基本找貓。每個視角有獨立ROI；同一物件可明確連到其他視角的同一邏輯識別，不能靠型號或IP猜測。

照片特寫只可作參考，不能自動知道攝影機全圖的座標。沒有可靠角度讀回不填座標；幾何對位亦不是電機位置讀回。此前曾試行三分頁、照片 polygon 裁切、物件 crop 縮圖與本機參考方向綁定；依目前 UX 決定，這些操作不再放在寵物檔案頁。寵物身分只需名稱與參考照片，不需 camera angle 或 PTZ 綁定。詳見[三項接線驗收](V4_3_THREE_GAPS_ACCEPTANCE_2026-10-16.md)。
