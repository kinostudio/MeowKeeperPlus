## 變更

- 清理全專案 156 項既有 lint 問題：匯入、型別缺漏、未使用變數、控制流程，以及選用功能的具體例外與安全備援；未關閉 lint 規則、刪除回歸測試或放寬權限。
- 系統安裝版由使用者核准一次 UAC 註冊固定更新工作，後續在本機 Dashboard 明確確認中斷後套用官方完整簽章包。不是差量下載，也不是零停機 hot patch。
- Host 啟動與監控啟動／重啟檢查所屬互動 Tray；缺少才補啟動，未見程序不宣稱成功，不在 Session 0 建立不可見 GUI。完整關閉會取消後續補啟動。
- 更新工作在 App 外的受保護 Updater 目錄執行，避免占用待替換目錄；固定 SYSTEM 身分、路徑、命令與套件簽章驗證不變。
- 修正 PowerShell Task Scheduler 根目錄應用單一反斜線，並讓更新驗證工具在 embedded Python 下自行設定來源匯入路徑。

## 驗收階段

來源 lint／compileall、固定來源完整測試、故障回歸門檻、包內 runtime／逐檔校驗均須有本輪證據，不能沿用修改前紀錄。實際數量與來源指紋留在本機 reports 及包內回歸證據。

模型登錄整合測試使用臨時 SQLite 與既有模型登錄函式；測試 metadata 的零準確率為合成 fixture 值，不代表家庭實拍準確率。媒體整合測試僅使用 loopback 與合成影片，不新增正式攝影機上游、不送 Telegram。

## 安裝後才驗收

1. 使用者手動執行候選包 Install-MeowKeeperPlus.cmd -Upgrade，自行確認 UAC。
2. 核對安裝 manifest、Core／Tray／更新排程、Data 路徑與執行帳號；不得以原包版本標籤假定執行中原始碼一致。
3. 確認正常攝影機、AI、錄影與通知。關閉所屬 Tray 程序後，分別驗證核心啟動與服務重啟能恢復單一互動 Tray；需要看到真實圖示與可用選單，不能只依程序存在。
4. 在可恢復的受控環境驗收一鍵套用、簽章拒絕、更新失敗與資料／App／排程回復。不得為測試擅自破壞正式資料或繞過簽章。
