# V0.2B 24H 行為優先推論報告

## 範圍

本階段將 V0.2 的主流程調整為「行為先、身分後」：影音接收與壓縮環形快取不得被
AI 阻塞；YOLO／BoT-SORT 與低成本規則先產生行為事件；DINOv2 身分工作以 LOW 優先級
在背景執行；Telegram 使用有界背景佇列。

完整 24 小時與 MX250 實機數據必須由目標電腦另行填入。本文件不把目前開發機結果當成
MX250 效能證明。

## 固定契約

| 項目 | `mx250_minimum` 預設 |
|---|---:|
| 最低系統 RAM | 8 GiB |

| DINO 複核間隔 | 10 秒 |
| DINO 工作逾時 | 3 秒 |

## 實作的優先級

1. Priority 0：單一媒體入口、影像／音訊時間戳與壓縮環形快取。
2. Priority 1：YOLO 貓咪偵測、BoT-SORT、軌跡／區域／動作與規則行為。
3. Priority 2：事件在身份未知時先落地，並將必要 Telegram 送出移到背景。
4. Priority 3：DINOv2／色彩身分解析；新 track、unknown、低信心或複核到期才排程。
5. Priority 4：統計與資料匯出，未納入即時主迴圈。

## 執行結果

以下欄位由每次實測命令填入；`not_checked` 表示尚未取得足夠實機證據：

| 指標 | 結果 |
|---|---|
| 實際推論後端 | 目前 RTX 2060 開發機的 PyTorch 為 CPU build，YOLO／DINO 實測皆 CPU；MX250：`not_checked` |
| YOLO 平均延遲 | GPU probe 單張 cat.jpg CPU 約 2,195 ms；不是 MX250 證明 |
| DINOv2 平均延遲 | GPU probe 單 crop CPU 約 489 ms；不是 MX250 證明 |
| 每分鐘 DINO 呼叫次數 | 由 `identity_requests`／實際影片時長計算 |
| GPU／CPU 使用量 | `tools/gpu_probe.py` 或目標機資源監控填入 |
| VRAM 峰值 | `not_checked`（無 CUDA 時不宣稱） |
| AI 影格丟棄數 | `pipeline.metrics.ai_frames_dropped` |
| 環形錄影完整性 | 單元契約：影音不可因 AI 丟幀；30 分鐘壓測：`not_checked` |
| 身分未知比例 | 由事件／track 統計填入 |
| 行為事件建立數 | `pipeline.metrics.behavior_events_created` |
| 降級與恢復 | 單元測試覆蓋；實機溫度／OOM 恢復：`not_checked` |

### 2026-08-01 開發機證據

- `nvidia-smi`：NVIDIA GeForce RTX 2060、6,144 MiB、driver 581.57、compute capability 7.5。
- PyTorch：`2.13.0+cpu`，`torch.cuda.is_available() = False`。
- ONNX Runtime 列出 `TensorrtExecutionProvider`、`CUDAExecutionProvider`、
  `CPUExecutionProvider`；本次 `.pt` YOLO 並未使用 ONNX Runtime CUDA。
- `gpu_probe.py --run-model-tests` 能以 CPU 真實找到 cat class 15，DINOv2 產生 384 維向量。
- 本地 `reports/cat_test.mp4` dry-run：5 個媒體影格、2 次 YOLO、3 張普通 AI 影格依負載策略
  略過；這些影格未從環形影音來源丟棄。影片完整性與 30 分鐘壓測仍是 `not_checked`。
- 單元測試驗證 `CompressedRingBuffer` 保存壓縮片段、`LatestFrameQueue` 只淘汰舊 AI 影格，
  不把兩者混成同一個無界佇列。

## 建議驗證命令

```powershell
python tools\gpu_probe.py --run-model-tests --output reports\gpu.json
python tools\run_v02.py --source-url <local-video> --disable-identity --max-frames 10
python -m unittest discover -s tests -v
python -m ruff check src tools tests
python -m compileall -q src tools tests
```

`--run-model-tests` 只載入本地已驗證模型，不下載權重。未提供 RTSP、Telegram Token 或
GPU 時保持 `not_checked`／CPU fallback，不猜測來源、不傳送外部訊息。

## 已知限制

- 尚未在 MX250 實機完成 30 分鐘、24 小時或 72 小時持續串流壓力測試。
- 現有規則行為仍需家庭實拍資料校正；`running` 不會直接等於 `playing`。
- BoT-SORT `track_id` 不是永久身分；遮擋、鏡頭移動或 ID switch 仍需實測。
- DINOv2 目前是低優先、CPU／CUDA 可替換的個體特徵原型，不是家貓身份保證。
- CUDA OOM 與溫度狀態已提供可測試的降級契約，實際 NVML／驅動數據需在目標機填入。

## 與 MVP Release Gate 的關係

本報告只證明 V0.2B 的行為先／身分後程式契約與本機短測，不代表 24 小時服務已通過驗收。
身分辨識、寵物登錄、規則式行為與統計仍屬 `experimental`，尚未用家庭攝影機資料完成
precision／recall 或 ID switch 驗收。MVP 的來源重連、FFmpeg watchdog、SQLite WAL／migration、
日誌輪替、磁碟保留與可攜式建置證據集中於 `docs/MVP_RELEASE_GATE_REPORT.md`。
