# r117 整合與安全更新候選（2026-11-05）

## 版本基準

整合 `main` 的 `6ed31ca` 與候選修正 `f255b64`，不是用整個目錄互相覆蓋。保留事件影片保留設定、通知設定、服務配額接口與三秒拼貼／雲端影片說明修正。

## 更新契約

- 移除直接從 Git 覆蓋正式 App 的背景端點與操作。舊工具入口只提示改用 Dashboard，不再複製檔案、執行 UAC 或重啟服務。
- 使用已下載的官方簽章套件；固定 SYSTEM 工作重新核對簽章、ZIP SHA-256、完整檔案清單、版本及固定安裝路徑。包內版本必須與簽章清單一致。
- 由使用者在本機 Dashboard 明確確認短暫中斷，不是零停機或差量 binary patch。
- 在停止舊程序後、切換 App 前，保存 Data 快照及雜湊。包含資料庫、設定、寵物與事件媒體；不複製暫存 cache／updates。SQLite 使用 backup API，不直接複製執行中的 WAL。
- 空間須足以保留快照及失敗現場，否則停止更新。較大的事件資料會增加備份時間與空間需求。
- 切換前先保存復原紀錄。失敗時核對原版本、復原 App、Data 與全部工作定義，再啟動舊工作及確認健康；還原失敗不得回報成功。
- 更新失敗保留受保護快照、失敗資料與交易現場；不在 finally 無條件清除。成功後才清理交易暫存。
- 更新驗證／安裝子程序有界等待，非零結束碼不能當作成功。

## 公開原始碼安全

不得保存固定憑證的操作腳本。已加入第一方原始碼憑證樣式掃描，建置前強制執行；只回報檔名，不輸出匹配值。刪除目前檔案不會清除既有 Git 歷史，暴露憑證必須另行撤銷；不得把掃描通過當作歷史憑證已失效。

共用視覺金鑰新寫入改用 Windows 機器 DPAPI 加密及既有本機存取控制；仍可讀取本機歷史格式。這不代表跨電腦可直接搬移秘密。
