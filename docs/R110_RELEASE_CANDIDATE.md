## 已納入

- 非阻塞 GPU 採樣、細分分析／佇列耗時、歷史降階原因與目前預算分開；保留手動恢復與安全降階。
- 活動採樣與外層上限的雙重節流回歸修正，不提高安靜模式或繞過負載保護。
- 事件影片跨資料目錄尋回、安全遷移與失敗 journal 保留；原資料衝突時停止，不混合 SQLite。
- 選用官方 PawnIO 固定來源／簽章／雜湊驗證；另有固定 CPU-only SYSTEM 工作與受保護快取，不改驅動 ACL、不開網路埠、不接受任意命令。
- 明確 `-UserHost` 選項讓 Core 在原使用者登入後執行；使用者憑證不搬成 SYSTEM。這不是無人登入啟動模式，後續手動升級仍應沿用這個選項。
