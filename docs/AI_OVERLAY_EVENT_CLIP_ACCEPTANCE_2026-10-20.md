# 即時偵測框事件影片驗收（2026-10-20）

## 範圍

以使用者提供的事件影片離線檢查 YOLO 偵測輸出，並驗證該正規化框可由 Dashboard 疊圖元件映射到預覽尺寸。沒有連線或修改正式 Host，也沒有把影片複製進 repository。

## 發現與修正

- 即時 API 將每筆分析結果直接覆蓋目前 overlay；空 detections 會立即刪除上一筆仍新鮮的正向框。由於瀏覽器約每秒輪詢、AI 推論有自己的採樣節奏，正向結果可能剛好落在輪詢之間，或在前端下一次取得前被空樣本蓋掉。
- 改為同一來源 epoch 內暫存最近正向偵測，空樣本只在原始取樣仍未超過 2 秒時沿用；過期、時間倒退／格式錯誤、來源 epoch 變更均清除。正向新樣本立即取代舊樣本，仍最多保留 20 個框。
- 影片中有兩隻可見貓。離線 YOLO 在 960 px、conf=0.1 的探測下，多個抽樣時點都找到平台上的貓；5 秒樣本信心值約 0.6855，原始影格 3840×2160 的框約為 `[1929.4, 185.1, 2295.3, 405.7]`。床上的另一隻沒有穩定達到正式 0.55 門檻；此修正不改模型門檻，也不聲稱第二隻已被辨識。

## 驗收結果

- `tests.test_live_overlay.LiveOverlayTests`：驗證正向框在 2 秒窗內經空樣本仍保留、超時與來源 epoch 變更清除、新正向結果取代舊結果且數量受限。
- `tests/js/ai_overlay_runtime.cjs`：以事件影片實測框座標驗證 3840×2160 影格映射到 960×540 預覽的 left/top/width/height；亦覆蓋標籤文字安全、無效框、逾時與閒置清理。
- `tests.test_preview_mse.PreviewMseContractTests.test_async_preview_and_overlay_regressions`：執行上述前端 runtime 回歸。
- 正式 Host 的即時實機畫面：`not_checked`。離線影片與隔離 DOM/runtime 測試不能替代正式 Dashboard 上的攝影機即時驗收。

## 仍有限制

疊圖是最近 AI 採樣的座標，不與每個影片 frame 同步；場景內物體移動時可能短暫偏移。未在 2 秒內取得正向偵測時會隱藏，不會為了持續顯示而沿用過期框。身分及動作仍是 experimental；模型漏檢需另行改善，和框的呈現問題分開處理。
