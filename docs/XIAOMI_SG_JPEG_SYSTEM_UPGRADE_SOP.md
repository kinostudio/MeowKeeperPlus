# Xiaomi 來源與 Windows 升級診斷

本頁只提供通用操作。帳號區域由裝置探索與登入結果判定，不依攝影機型號寫死區域，也不以歷史成功推定目前來源有效。

1. 先讀取攝影機原生隱私狀態；停用拍攝時清楚顯示原因，恢復拍攝需使用者操作。
2. 分別檢查本機路由、目前網路 profile、go2rtc 程序及設定、單張影格與持續取流。串流註冊不代表影格已接通。
3. 防火牆只對已驗證程式、攝影機位址與所需協定建立受限規則，經明確核准後由管理員操作。
4. Windows 終端若進入選取模式，可能暫停前景程序。先解除選取，再檢查既有程序進度；不要無條件重跑安裝。
5. 升級依來源 manifest、Host 程序與資料根目錄確認。使用者執行發布包的安裝入口，影音與通知實機驗收另列。

一次性命令、PID、網路位址與實際量測封存於本機。詳見 [建置與安裝](BUILD_WINDOWS.md)、[工程閉環](ENGINEERING_FEEDBACK_LOOP.md) 及 [來源接入](XIAOMI_GO2RTC_INTEGRATION.md)。
