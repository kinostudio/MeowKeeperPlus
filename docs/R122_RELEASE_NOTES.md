# R122 介面與品牌更新

- 即時畫面改為影像與鏡頭控制雙欄；小螢幕依序排列，保留原有控制及驗證流程。
- 事件篩選、待確認清單與表格式紀錄沿用原有播放／人工覆核介面；篩選僅作用於已載入頁面。
- 新增設定總覽、分組 AI／錄影設定與手機底部分頁；使用說明以彈窗呈現。
- Dashboard 使用透明雙貓 Logo 及本機無襯線字體。Tray 共用同一雙貓原圖，只疊加正常／等待／異常角標，不重繪貓咪。
- 修正說明泡泡撐寬頁面、通知未傳送卻顯示成功、及高畫質快捷選項漏掉 subtype=3。高畫質優先沿用已驗證規格；畫質代碼不保證跨攝影機解析度。
- 身分與行為仍屬實驗性；Telegram 接受訊息不等於收件者已閱讀。隔離測試不代表家庭實拍辨識率或真實鏡頭到位。

差量更新須驗證既有版本、精確檔案基準、官方簽章及更新後健康狀態；失敗保留回滾。不適用時停止，不自動改下載完整執行環境。
