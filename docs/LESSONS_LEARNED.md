# 可重現故障與工程原則

私人實機紀錄另存本機。本頁只保存通用解法；既有測試結果不代表目前部署狀態。

- **原始碼交接**：來源檔與測試需同時交付，記錄基準／完成 commit 及每檔雜湊。來源快照沒有 Git 歷史；含 .git 的協作目錄使用 fetch／分支整合。回歸：tests.test_source_handoff、tests.test_argon_sync。
- **學習證據**：已標註、eligible 或已有向量的證據不進入一般容量／期限淘汰；不能以另一條超長期限刪除規則繞過保護，也不能重寫證據時間冒充保留。回歸：tests.test_feedback_learning。
- **視覺設定**：切換模型仍需保存當次額度／品質修改；空白模型可保存未啟用草稿。秘密與設定分離；私人區網位址不代表傳輸已加密。回歸：tests.test_vision_settings。
- **Windows 身分**：執行使用者不同會影響 Credential Manager／DPAPI；先確認程序身分，再診斷授權，不擅自重登或刪除憑證。
- **資料與事件媒體**：各入口使用同一資料根目錄；歷史事件路徑須在允許根目錄中驗證，檔案存在不等於瀏覽器可播放。
- **影音與 AI**：程序存活、連線存在、新影格、推論完成及事件保存是不同證據。初始化／warmup 與穩態耗時分開；GPU unavailable 不得替換為0%。
- **發布與程序**：停止所屬程序需處理 PID 已退出的競態；封存、複製、校驗及啟動各階段分開記錄，失敗不得假稱完整回滾。
- **驗證環境**：明確指定專案 Python、模型與工具；缺依賴造成的匯入錯誤須先解決環境，再判定程式行為。高規開發機不代表最低規格硬體。

具體門檻見 configs/release-regressions.json 與 [工程閉環](ENGINEERING_FEEDBACK_LOOP.md)；私人歷史報告不能替代當次測試。
