# MeowKeeper+ Windows 使用指南

本指南只說明一般操作，不包含任何家庭攝影機、帳號、硬體或實機測試紀錄。

## 啟動程式

- **安裝版**：從 Windows「開始」選單開啟「喵喵守護者+」。登入 Dashboard 後，背景服務可依安裝設定持續運作。
- **可攜版**：先將完整發布包解壓到固定資料夾，再雙擊包內的 MeowKeeper+ 啟動器。保持整個資料夾在一起；程式設定與事件資料會保存在該可攜包指定的資料目錄。
- 若程式已完整關閉，使用相同的開始選單項目或可攜版啟動器重新開啟即可。

## 第一次連接攝影機

1. 在 Dashboard 的「來源與攝影機」頁登入或準備攝影機連線。
2. 選擇本機連線；只有攝影機在其他網路、且已完成安全配對時，才選擇中繼連線。
3. 按「接入監控」，等待系統取得新影格，再到「即時畫面」確認畫面是否持續更新。
4. 若顯示已連線但沒有影格，依序確認攝影機有電、隱私開關已開、來源仍有效，再使用 Dashboard 的連線診斷。防火牆修復應只允許指定程式與必要來源，不要關閉整體防火牆。

連線程序已啟動、取得單張影格及持續播放是不同狀態，請以各自的實際畫面和時間戳判斷。

## 即時畫面與 AI 候選

- 「節能」用較低頻率更新預覽；「流暢」嘗試連續播放；「休眠」停止此頁的畫面更新。播放模式不會改變攝影機本身的錄影設定。
- 「截圖」和「錄影（15秒）」會把結果保存在主機的 photo／video 資料夾。影片取自按下前的事件快取；剛啟動時可能不足 15 秒。
- 偵測框、身分候選與動作候選是 AI 分析結果，不是原始影片內容。模型可能漏掉目標或產生誤判；身分與行為仍是實驗性候選，請以人工確認為準。
- 改變 AI 尺寸或速度會增加運算需求。使用程式提供的負載保護；不要為了提高數字而強制 GPU 滿載。

## Telegram 通知

Telegram 是選用功能。請只在 Dashboard 輸入自己的 Bot 設定與收件對話；不要將 Token 貼到公開討論、截圖或診斷報告。是否成功送達以回條／Dashboard 狀態為準，通知已啟用不代表每則訊息都已送達。

## 備份與升級

- 使用 Dashboard 的完整資料備份功能保存設定、事件索引、寵物檔案和其他應用資料；請依介面要求設定並妥善保存備份密碼。
- 升級前先停止目前版本的程式，下載官方發布包並依包內步驟升級。不要將不同版本的程式檔混放，也不要把舊資料覆蓋到程式碼或模型資料夾。
- 安裝版與可攜版的資料目錄不同。跨電腦搬移請優先使用完整備份／還原；若手動搬移，應依實際執行中的資料目錄及該版本遷移說明操作，避免混用兩份 SQLite 資料庫。

## 遠端私人存取

MeowKeeper+ 預設以本機運作。若需從外部網路查看，主機與觀看裝置都需加入同一個私人加密網路，並使用登入保護的 Dashboard；不要直接公開攝影機、RTSP 或 go2rtc 管理 API。參考 [Tailscale 官方下載頁](https://tailscale.com/download)。

## 故障排查

- **畫面空白**：檢查攝影機供電與隱私狀態，確認來源設定和連線方式，再重新讀取最新影格；不要連續建立重複串流。
- **AI 沒有框**：確認 AI 分析狀態與最近分析時間。沒有框不代表攝影機串流中斷，也不應用手工框選冒充模型偵測。
- **通知未送達**：確認 Telegram 通知已啟用、收件者設定正確，再看送達回條或診斷摘要。不要分享 Token 或未遮罩日誌。
- **遠端連不上**：先確認兩端私人網路都在線、Dashboard 可登入，再使用連線診斷；不要把服務埠開放至公網。

若需要回報問題，請只分享已移除帳號、地址、Token、家庭影像與本機路徑的摘要。
