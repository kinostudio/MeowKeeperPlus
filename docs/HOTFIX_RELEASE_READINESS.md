## 追加修正與證據

- Task Scheduler 根路徑使用單一反斜線；Windows 實際 COM 唯讀核對確認雙反斜線不被接受。回歸由安裝器接線測試固定。
- 更新工作以固定 SYSTEM 身分及受保護 Updater 作為工作目錄，避免占用待替換 App；驗證工具自行加入來源匯入路徑，可由 embedded Python 直接啟動。
- PTZ 執行檔與 manifest 必須在建置複製前存在；第三方混合編碼輸出以明確解碼與替代策略處理，保留真實結束碼，不讓日誌解碼執行緒誤導檢查。runtime 實際匯入及 pip check 另行通過。
- Windows FILETIME 與 Python 時間換算存在約微秒級誤差；僅放寬未來方向 1 毫秒的捨入容差，5 秒新鮮度與移動後影格下界不變。新增未來／過期拒絕回歸；位置測試修正後重複 10 次通過。
- Host 啟動與監控啟動／重啟檢查 Tray，缺少才補啟動。互動 Session、同一程式、連線埠與 lock root 分開核對，關閉後不補開。
- 舊試跑包含來源變動或偶發位置失敗的紀錄已作廢，不作為放行依據；最終結果以本節固定來源紀錄為準。
