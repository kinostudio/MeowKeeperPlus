# 產品化規格

MeowKeeper+ 以本機運作為核心。影音／快取優先，之後依序為偵測、事件與通知、身分候選及統計；選用功能失敗不得阻塞主路徑。

## 必要行為

- 每台攝影機維持必要的單一上游，本機分流預覽、AI 與事件快取。
- 首頁與即時頁分開顯示來源規格、實際播放及 AI 分析；連線成立不等於收到新影格。
- 休眠、節能與流暢預覽提供明確狀態及降級原因；前端疊圖可獨立開關。
- 原始截圖優先、15秒回溯錄影顯示實際長度，保存提示不攔截操作。
- 人工回報可標註個體與行為；品質合格且標註一致的特徵獨立保存。新軌跡不得淘汰已保護的人工證據。
- API 圖片分析為選用功能；圖片外送需同意、額度有界，失敗時本機錄影及通知繼續。
- API 金鑰經 Windows 安全儲存保存；輸入金鑰限本機或 HTTPS。
- CPU／RAM／GPU 指標保留來源、採樣時間及 unavailable 狀態，不以零代替無法讀取。
- GUI 啟動器、Tray 及 Host 使用相同資料根目錄；完整關閉只停止本程式所屬程序。
- Tailscale 遠端存取保持私人連線；不直接信任外部轉送標頭辨識裝置。

## 正式產品門檻

隔離回歸、完整測試、乾淨套件與實機驗收分開記錄；實機影像與量測留本機。需補足目標硬體長測、家庭身分辨識校準、多瀏覽器播放、通知端到端、備份還原、升級回復及容量管理。

可重現故障需有可執行測試及故障台帳；發布前檢查當次程式指紋。來源協作以 commit 為準，安裝狀態以正式 Host 回報及檔案證據為準。

方法見 [架構](ARCHITECTURE.md)、[測試](TESTING.md)、[安全](SECURITY.md) 及 [工程閉環](ENGINEERING_FEEDBACK_LOOP.md)。
