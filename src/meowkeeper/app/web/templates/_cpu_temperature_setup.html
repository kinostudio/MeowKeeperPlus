啟用／檢查 CPU 溫度監測

想知道電腦是否過熱？這是選用功能；尚未啟用不影響攝影機、錄影或 Telegram。

  1. 在執行監控的那台電腦開啟本機儀表板，按下方按鈕。
  2. 親自確認提示、Windows 管理員授權與官方 PawnIO 安裝視窗；只選官方受限版，不選 Unrestricted。
  3. 完成後按「更新溫度狀態」，等候背景採樣。只有取得真正感測值才算成功；官方若要求重新開機，請自行安排。

會從官方來源下載並驗證 PawnIO 2.2.0，建立僅讀 CPU 的受限 SYSTEM 測溫工作；不更改 Host 帳號、不自動重開機，也不會自動安裝。

正在確認此主機能否開啟授權視窗…

從手機或另一台電腦觀看時，無法在這裡啟動安裝。請到監控主機操作；也可在程式主資料夾雙擊 Enable-CPU-Temperature.cmd，不需輸入命令。
