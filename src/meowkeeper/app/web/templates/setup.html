1 · 註冊儀表板

2 · 綁定攝影機

登入後到「來源與攝影機」。選小米、RTSP 或 YouTube，保存並啟動監控；看到有效新影格才算接通。

{{ icon('send') }}

3 · 讓手機和 Apple Watch 收到貓咪影片

到「通知設定」，依引導建立 Bot、傳送 /start、安全保存收件者，再啟用通知並發送測試。手機收到測試，才算設定完成。家中偵測到貓咪時，喵喵守護者+ 會把事件影片傳到 Telegram；Apple Watch 可直接收到並播放。上班不方便拿手機時，也能從手錶快速查看事件影片、關心家中貓咪。這是事件影片，不是持續直播。

基本流程：註冊 → 接通畫面 → 驗證通知。停止監控會停止影音與 AI；只關閉網頁不會停止背景守護。

人在外面用手機看家（進階、可選）

MeowKeeper+ 以本機運作為核心，預設不會把監控服務公開到網際網路。在家中主機和手機安裝 官方 Tailscale，並登入同一個私人網路；主機保持開機後，到「連線與安全」檢查遠端網址。人在外面即可透過加密的私人連線安全開啟家中即時畫面和控制介面。Tailscale 會嘗試點對點直連，若網路限制則可能使用加密中繼；兩種都不會開放公網。可操作功能依攝影機來源支援而定。

  1. 使用剛建立的管理者帳號登入。
  2. 到「設定 → 來源與攝影機」加入 RTSP 或 YouTube 來源；小米攝影機可使用專用設定精靈。
  3. 到「設定 → Telegram」設定通知。

請只在本機 Dashboard 設定 RTSP 密碼與 Telegram Bot Token；不要把密碼、Token 或攝影機網址貼到 Codex 或其他聊天。
